# Fatia 3.3 — projeção e tela Parcelas (+ Previsto)

Data: 2026-10-02 · Spec da fatia: [`2026-09-30-fatia-3-design.md`](2026-09-30-fatia-3-design.md) (§4, §5 Parcelas)

## 1. Decisões do brainstorming

- **"O que caberia na renda" entra agora.** `planoSaudavel` é portada na 3.3,
  não na 3.5. Sem renda gravada, a coluna mostra o vazio do legado com link para
  Ajustes; quando a 3.4 gravar a renda, ela passa a funcionar sem mudança.
- **Uma tela só.** Em `/parcelas`, o Previsto vem em cima ("quanto vem") e as
  parcelas embaixo ("de onde vem"). Menu não muda; não há rota `/previsto`.
- **Visual do legado, sem corte.** O bloco de parcelas segue a captura
  `docs/legado/telas/parcelas.png`, mas mostra todas as compras e todos os meses
  (o legado cortava em 8 compras e 6 fichas porque era um bloco do painel).
  Cada linha ganha o cartão. Os itens de cada ficha de mês ficam acessíveis por
  teclado e toque, não só por `title`.
- **Mês passado compara com o real**, como no legado: se o mês seguinte ao base
  já foi importado, a faixa diz "Previsão feita para …" e mostra o real e a
  diferença percentual.
- **Fora:** barra prevista no gráfico "Ritmo mensal" (não existe gráfico de
  ritmo nesta fatia) e campos de renda inline (vão para Ajustes, 3.4).

## 2. Cálculo

### Porta

- **`projecao(ctx)`** em `src/lib/calculos/parcelas.ts`, linha a linha de
  `docs/legado/calculos-do-app-antigo.js` (o texto é idêntico ao de
  `app-antigo.html`). Devolve `{ prox, parcelas, fixos, variavel, total, real,
  meses }` ou `null` sem mês. Com `mesFiltro = 'TODOS'`, `mesAtual` é `null` e a
  função usa o último mês disponível, como no legado.
- **`planoSaudavel(ctx, pj)`** em `src/lib/calculos/plano.ts` (arquivo novo, que
  a 3.5 completa). Os globais `renda`, `metaPoupanca` e `foraCartao` do legado
  viram campos do `Contexto`. Devolve `{ teto, compromissos, disponivel,
  poupanca }` ou `null` sem projeção; `teto` e `poupanca` são `null` sem renda.

### Contexto

- `Contexto` ganha `renda`, `metaPoupanca` e `foraCartao` (números).
- `carregarContexto` lê `renda_declarada`, `meta_poupanca` e
  `gasto_fora_cartao` de `user_setting` (`where user_id = $1`). Sem linha:
  renda 0, meta 20, fora 0 — os defaults das colunas.
- O retorno `renda` à parte de `carregarContexto` some; quem o usava (painel)
  passa a ler `ctx.renda`.
- Filtro de cartão e "separar obra" continuam no adaptador, então valem para a
  projeção sem código novo: com obra separada, "Construção / Obras" sai do
  variável, das fixas e das parcelas.

### Modelo da tela — `src/lib/calculos/previsto.ts`

`previsto(ctx)` devolve `null` quando `projecao` é `null` ou `total` é 0; senão:

```
{
  prox, total, parcelas, fixos, variavel, meses,
  real: number | null, dif: number | null,          // dif = real/total - 1
  pctRenda: number | null,                          // total/renda, só com renda > 0
  padrao: { parcelas, fixos, variavel, vazio },     // larguras em %
  renda: null | {
    teto, compromissos, disponivel, poupanca,
    sobra,                                          // teto - total
    corte, pctCorte,                                // variavel - max(0, disponivel)
    porSemana, porDia,                              // disponivel/4.3, /30, só se > 0
    larguras: { contratado, paraEscolhas, vazio },     // "sobra" já é teto - total
    estado: 'ok' | 'alerta' | 'ruim',
    veredito: 'compromissos-acima' | 'cabe' | 'cortar',
  }
}
```

- Escala das barras: `max(total, teto ?? 0, 1)`, como `renderPrevisto`.
- `estado`: `total <= teto` → `ok`; `total <= teto * 1.1` → `alerta`; senão
  `ruim`. Com `disponivel < 0` o veredito é `compromissos-acima` e a cor é
  `ruim`.
- O texto de cada veredito fica no componente, com as frases do legado.

## 3. Tela `/parcelas`

Server component no mesmo esqueleto de `categorias/page.tsx`:
`exigirUsuario()` → `lerFiltro` → `opcoesDoFiltro` → `carregarContexto` →
`previsto(ctx)` e `parcelasInfo(ctx)` → JSX. Componentes em
`src/components/parcelas/`.

1. **Cabeçalho**: "Parcelas" e o mês base (`rotuloMes`, ou "todos os meses").
2. **Faixa da projeção**: "Sua fatura de out/26 já começa em R$ 3.640", as três
   partes (parcelas já compradas, fixos, variável média de N mês/meses) e a nota
   "Parcelas e fixos já estão contratados — só o variável depende do que você
   fizer daqui para frente." Com `real`: "Previsão feita para …", "real: R$ X
   (±Y% vs previsto)" e a nota de comparação do legado.
3. **Duas colunas** (lado a lado no desktop, empilhadas em 390px):
   - **Pelo seu padrão** — "o que out/26 deve custar se nada mudar", valor,
     barra empilhada (`--s-parcela`, `--s-fixo`, `--s-escolha`), legenda com
     valores, "Equivale a X% da renda prevista" quando há renda.
   - **O que caberia na renda** — sem renda: subtítulo "informe a renda prevista
     para calcular o teto", texto do legado e link "Informar renda em Ajustes"
     preservando o filtro. Com renda: "guardando M% de R$ R[ e tirando R$ F de
     gastos fora do cartão]", teto, barra (contratado, sobra), linhas (já
     contratado, sobra para as escolhas, por semana e por dia quando > 0,
     guardado no mês) e o veredito colorido.
4. **Parcelas já compradas** — título e subtítulo da captura. Uma linha por
   compra: descrição, cartão, "faltam n de N · R$ v/mês", total restante
   (centavos). Fichas com todos os meses à frente (`mês R$ total`); cada ficha
   abre a lista de itens ("Notebook Dell 4/12") por clique, toque ou teclado.
   Rodapé: "Já comprometido · lido das faturas mais recentes de N cartão/cartões"
   e o total.
5. **Obra separada**: a linha `painel-obra` das outras telas, quando ligada e
   com valor ≠ 0.

Totais em `moeda0`; linhas de compra e rodapé em `moeda`, como o legado.

## 4. Estados e erros

- **Primeiro uso** (nenhuma fatura): "Importe uma fatura para começar" com o
  botão de importar, igual a Categorias.
- **Sem projeção** (`previsto` nulo): no lugar da faixa e das colunas, "Sem
  dados suficientes para projetar o próximo mês." O bloco de parcelas continua.
- **Sem parcela em aberto**: "Nenhuma compra parcelada em aberto nas faturas
  mais recentes."
- **Recorte vazio** (cartões escolhidos sem fatura): vazio com "Ver todos os
  cartões".
- `src/app/(app)/parcelas/error.tsx` com retry, copiado de Categorias.
- Só leitura, sem IA, sem rota nova. `user_id` da sessão; posse no `where` do
  adaptador.

## 5. Testes (`scripts/testes.ts`)

- Paridade `projecao` nos quatro recortes de fixture (recente, 2026-04, TODOS,
  2025-01).
- Paridade `planoSaudavel`: o harness extrai a função de `app-antigo.html` por
  regex (lança erro se não achar) e roda com renda 0, renda > 0 e renda > 0 com
  fora do cartão > 0.
- `previsto`: larguras somam no máximo 100; os três vereditos e o estado
  `alerta` (até 10% acima do teto); `real`/`dif` com mês passado; TODOS usa o
  último mês; obra separada some do variável; `pctRenda` nulo sem renda.
- `carregarContexto` sem linha em `user_setting` → defaults (testado na função
  pura que monta a configuração, não no banco).

## 6. Conferência

Dono no navegador autenticado: 390px e desktop, claro e escuro, teclado nas
fichas, mês passado (real × previsto), TODOS, obra separada, sem renda.
