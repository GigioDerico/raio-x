# Tarefa 3.7 — Ajustes: Inteligência artificial e Seus dados

Data: 2026-10-03 · Guia: [`docs/guia-de-construcao.md`](../../guia-de-construcao.md), seção "Ajustes" · Plano técnico: seção "IA: automático × sob demanda"
Base: tela `/ajustes` da 3.4 ([spec](2026-10-02-fatia-3.4-design.md))

## 1. Decisões do brainstorming

- **O teto de IA só aparece, nunca bloqueia.** Ajustes mostra gasto × teto em
  destaque; importar PDF e refinar o plano seguem funcionando acima do teto.
  (Escolha do dono; o plano técnico previa parar as chamadas automáticas.)
- **"Apagar tudo" apaga todos os dados e mantém o acesso.** Usuário, senha e
  sessão continuam; Ajustes voltam ao padrão; o dono cai no app vazio.
- **Exportar é um CSV de lançamentos no formato do app antigo**, com duas
  colunas a mais, de todos os cartões e meses, ignorando o filtro da tela.
- **O uso de IA ganha tabela própria (`ai_uso`).** `ai_output` é cache por
  prompt (chave única por `input_hash`): reimportar o mesmo PDF contaria uma
  chamada só. `ai_uso` guarda uma linha por chamada, só com números.
- Achados que entram na tarefa: a extração de PDF não registrava custo; o
  "Refinar com IA" ignorava o modelo escolhido (a importação já o usava).

## 2. Migração `drizzle/0006_ia_uso.sql`

```sql
create table if not exists ai_uso (
  id         bigint generated always as identity primary key,
  user_id    uuid not null references app_user(id) on delete cascade,
  kind       text not null,             -- 'extracao' | 'plano'
  modelo     text not null,
  tokens_in  integer not null default 0,
  tokens_out integer not null default 0,
  custo_usd  numeric(10,6),             -- null: o OpenRouter não informou
  criado_em  timestamptz not null default now()
);
create index if not exists ai_uso_mes on ai_uso (user_id, criado_em);

alter table user_setting add column if not exists teto_ia_usd numeric(8,2);
```

`teto_ia_usd` nulo = vale `AI_BUDGET_USD_MONTH` do `.env`; 0 = sem teto.
Aplicada no Neon só com autorização do dono.

## 3. Bloco "Inteligência artificial"

### Registrar o uso

- `src/lib/ia-uso-repo.ts` (`server-only`): `registrarUso(userId, kind, modelo,
  uso)` → `insert ai_uso`. Falha ao gravar é registrada no log e engolida: a
  importação e o plano não caem por causa da contabilidade.
- `src/app/api/import/trecho/route.ts`: depois de cada `pedirJson` bem-sucedido,
  `registrarUso(userId, 'extracao', r.modelo, r.uso)`. Resposta não-JSON também
  custou: `RespostaNaoJson` passa a carregar `modelo` e `uso` quando o
  OpenRouter respondeu, e a rota registra antes de tratar o erro.
- `src/app/api/plan/route.ts`: o refinar passa `modelo: cfg.modeloIa` ao
  `pedirJson` (como a importação) e registra em `ai_uso` (`kind = 'plano'`),
  além do `ai_output` que já grava.
- Limite conhecido: quando o modelo principal falha e o de reserva responde,
  só a chamada que deu certo é registrada (`pedirJson` não devolve o uso das
  tentativas anteriores). O gasto mostrado pode ficar um pouco abaixo do real.

### Configurar

- Em `validarConfig` (`src/lib/ajustes.ts`), dois campos novos:
  - `modeloIa`: texto aparado, até 100 caracteres, formato
    `^[A-Za-z0-9._-]+/[A-Za-z0-9._:-]+$` (o slug do OpenRouter); vazio → volta
    ao `OPENROUTER_MODEL` do `.env`; fora do formato → erro "modelo no formato
    provedor/modelo".
  - `tetoIaUsd`: número pelo mesmo `lerNumero`; vazio → `null` (padrão do
    `.env`); de 0 a 9.999,99; fora → erro "teto entre 0 e 9.999".
- `salvarConfig` e `lerConfig` passam a ler e gravar `modelo_ia` e
  `teto_ia_usd`. Tela: dois `CampoAjuste` (tipos `texto` e `dinheiro`), com
  placeholder mostrando o padrão do `.env`.

### Gasto do mês (só leitura)

- `gastoDoMes(userId)` em `ia-uso-repo.ts`: soma de `custo_usd`, total de
  chamadas e chamadas com custo nulo, com `criado_em` no mês corrente em
  America/Sao_Paulo.
- `resumoGasto(gasto, teto)` (puro, `src/lib/ia-gasto.ts`) → `{ gasto, teto,
  chamadas, semCusto, pct, acima }`: `teto` efetivo = `teto_ia_usd ??
  AI_BUDGET_USD_MONTH`; teto 0 → sem teto (`pct` e `acima` nulos/falsos).
- Tela: "US$ 3,42 de US$ 10,00 este mês · 12 chamadas" com barra; acima do
  teto, barra e número em `--crit` e "passou do teto deste mês". "N chamadas sem
  custo informado" quando houver. Nada é bloqueado.

## 4. Bloco "Seus dados"

### Exportar — `GET /api/export/csv`

- Consulta todos os lançamentos do usuário, não excluídos e não suspeitos, com
  conta, instituição, fatura, categoria e parcela.
- `montarCsv(linhas)` (puro, `src/lib/csv.ts`):
  - colunas `mes_fatura;banco;cartao;data;estabelecimento_na_fatura;meu_nome;categoria;parcela;tipo;valor;cartao_apelido;fonte`;
  - BOM, `;`, toda célula entre aspas com `"` dobrado, `\r\n`, valor com
    vírgula decimal, parcela `n/N`;
  - `meu_nome` = apelido do lançamento, senão a descrição;
  - célula de texto que começa com `=`, `+`, `-` ou `@` ganha `'` na frente
    (injeção de fórmula no Excel). Valor numérico não passa por isso.
- Resposta `text/csv; charset=utf-8` com
  `Content-Disposition: attachment; filename="lancamentos-raio-x.csv"`.

### Apagar tudo — `POST /api/dados/apagar`

- Corpo `{ confirmacao }`; `confirmouApagar(texto)` (puro) só aceita
  `APAGAR TUDO` exato. Senão → `ErroDeUso('confirmacao', 'digite APAGAR TUDO
  para confirmar')`.
- `apagarTudo(userId)` (`src/lib/dados-repo.ts`, `server-only`), um `db.batch`:
  `account` (cascata em `statement`, `installment_plan`, `txn`), `txn`,
  `learned_label`, `plan` (cascata em `plan_target`), `ai_output`, `ai_uso`,
  `connection` (cascata em `sync_run`), todos com `user_id = $1`; `user_setting`
  volta aos padrões. Não toca `app_user`, `institution` nem `login_attempt`.
- Devolve `{ ok: true, conexoesApagadas }`. Revogar no Pluggy fica para a 4.1;
  se `conexoesApagadas > 0`, a tela avisa "as autorizações no banco podem
  continuar ativas; revogue pelo app do banco".
- Tela: "Apagar tudo…" abre `<dialog>` com o que some e "não tem volta"; campo
  para digitar; botão vermelho habilita só com o texto exato; sucesso →
  `/`.

## 5. Segurança

- `user_id` só da sessão; todo `select`/`update`/`delete` com `user_id` no
  `where` ou por cascata de linha do próprio usuário.
- Apagar só por `POST` com JSON; `GET` não apaga nada.
- CSV sem injeção de fórmula. `ai_uso` sem prompt nem resposta.
- Nenhuma `NEXT_PUBLIC_`; o modelo escolhido só vai ao OpenRouter, do servidor.

## 6. Testes (`scripts/testes.ts`)

- `validarConfig`: modelo válido, sem barra, com espaço, 101 caracteres, vazio →
  padrão; teto vazio → `null`, 0, negativo, 10.000, "abc".
- `confirmouApagar`: só o texto exato.
- `montarCsv`: cabeçalho, BOM, `;`, aspas, vírgula decimal, parcela, guarda de
  fórmula em texto e não em valor.
- `resumoGasto`: soma, chamadas, sem custo, percentual, teto 0, acima do teto.
- Repositórios e rotas: sem teste de banco; `curl` sem sessão → 401.

## 7. Conferência

Salvar modelo e teto; importar um PDF e ver o gasto subir; baixar o CSV e abrir
no Excel; abrir e cancelar o diálogo de apagar (sem confirmar).
